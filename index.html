Agent Blumee M2 rclone

A personal-use Google Drive file-transfer integration for the owner's M2 Mac.

What the integration does

The integration uses rclone to transfer the owner's selected market-data files, derived audit-source files, manifests, and operational reports between the M2 Mac and Google Drive. It supports the owner's existing data-maintenance automation.

This Google OAuth client identifies the file-transfer application. Access to Google Drive requires the account holder's separate authorization. This is not a public sign-up service and does not place brokerage orders.

Data access

The integration requests Google Drive read/write permission. That permission is broader than the folders selected in the local configuration; the selected folders are operational settings, not an OAuth permission boundary. Details are provided in the privacy policy.

About this website

This website contains only the application description and privacy information. It does not contain the owner's datasets, account credentials, OAuth tokens, workflow exports, or private logs, and it provides no Google sign-in form.

For questions, use the application administrator's support email displayed in Google's consent screen.
