Agent Blumee Conversation Worker

A personal Gmail account-pairing integration operated by Marc Blumenthal.

What the integration does

The current worker verifies a private communication link between the owner's configured mailbox and the Agent Blumee mailbox. After authorization, it checks the agent mailbox's identity, sends one pairing challenge to the configured owner, and validates the corresponding sent message and reply.

The current version is limited to this pairing operation. It does not offer public registration or ongoing general inbox automation. Completing pairing does not authorize future message processing.

Gmail access

The integration requests gmail.readonly and gmail.send. These Google permissions allow reading messages and settings and sending email for the authorized mailbox. They are broader than the worker's limited pairing behavior; the application enforces that narrower behavior. The OAuth grant itself is not restricted to a particular message or conversation.

Read the privacy policy for details about data use, service providers, retention, and revoking access.

About this website

This website contains the application description and privacy information. It contains no mailbox data, account credentials, OAuth tokens, private workflow exports, or operational evidence, and it provides no Google sign-in form.

For questions, use the application administrator's support email displayed in Google's consent screen.
