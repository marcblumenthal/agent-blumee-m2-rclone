Blumee Reply

A personal Gmail read-and-send authorization for the Agent Blumee conversation system.

What the application does

Blumee Reply is intended for the operator-authorized Agent Blumee mailbox. During setup it checks the OAuth grant and mailbox identity. After separate native-deployment approval, it may read the relevant conversation, send an authorized response, verify sent-message evidence, and reconcile uncertain delivery results. It is distinct from the read-only Blumee Reader application.

Requested Google permissions

https://www.googleapis.com/auth/gmail.readonly
https://www.googleapis.com/auth/gmail.send

These are mailbox-wide permissions, not Google-enforced limits to selected messages, threads or recipients. The service must separately enforce approved send and read controls. It does not request Gmail modification or deletion scopes.

Privacy and user control

Read the Blumee Reply privacy policy for details of message data access, processing, storage, user controls and revocation. Application use of Google data must follow the Google API Services User Data Policy, including its Limited Use rules.

Setup status: This informational page does not sign users in, send messages, or activate production operation. The Gmail authorization and controlled release are separate steps.

Contact

Contact agent.blumee@gmail.com for questions or privacy requests. No mailbox data, OAuth tokens, or account credentials are published here.
